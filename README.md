# Urvi Khardekar — Film & Media Portfolio

A responsive, single-page portfolio website built with HTML and CSS.

## Publish on GitHub Pages
1. Extract this ZIP on your computer.
2. Open your GitHub repository: https://github.com/kurvi07/Portfolio
3. Upload `index.html`, `style.css`, and `Urvi_Khardekar_Resume.pdf` to the repository root (top level, not inside another folder).
4. Commit the changes.
5. In the repository, open **Settings → Pages**.
6. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/(root)`, then Save.
7. Wait a few minutes and open the live site link shown in Settings → Pages. Your previously used GitHub Pages address was `https://kurvi07.github.io/Portfolio/`.

## Before sharing
- Confirm the contact details and all dates are correct.
- Add only photos, film stills, and showreel links you have permission to publish.
- The Short Horror Film project is marked in progress in the résumé.
- The résumé PDF is linked from the page as `Urvi_Khardekar_Resume.pdf`.
